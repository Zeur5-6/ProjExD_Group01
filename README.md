# RUN & MAGIC

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1

## ゲームの概要
* 主人公キャラクターの魔法使いを操作して、無限に続くステージを進みながら敵を倒す2Dアクションシューティングゲームです。
* 参考URL：[CUPHEAD](https://store.steampowered.com/app/268910/Cuphead/?l=japanese)

## ゲームの遊び方
* 矢印キーで魔法使いを操作し、敵の攻撃を回避しながら、スペースキー押下で火球を発射して敵を消し炭にする。
* ライフ（初期値3）が0になったらゲームオーバー。
* **基本操作**
  * `←` `→`：左右移動
  * `↑`：ジャンプ（空中でもう一度押すとダブルジャンプ）
  * `↓`（足場の上で）：足場をすり抜けて下に降りる
  * `SPACE`：通常火球の発射
  * `LSHIFT` + `SPACE`：5方向への拡散弾（弾幕）の発射
  * `Z`（空中）：無敵ローリング攻撃
  * `C`：向いている方向へ緊急回避（テレポート）
  * `X`：アイテムを消費してマップ全体攻撃
  * `ESC`：ゲームの終了

## ゲームの実装
### 共通基本機能
* 背景画像と主人公キャラクター、敵、足場の描画、および基礎動作（移動・ジャンプ・射撃・カメラ追従・無限マップ生成）

### 分担追加機能
* 残機機能（担当：奥山）：`Life` クラスを実装。初期残機を3とし、画面右下（下から50px、右から50px基準）に魔法使いアイコンを描画する。敵本体や敵の攻撃が当たったときに残機が1減少し、0になるとゲームオーバーになる機能。
* 拡散弾機能（担当：奥山）：`NeoBeam` クラスおよび `PlayerBullet` クラスの角度指定処理を実装。左シフトキーを押しながらスペースキーを押下した際、`-50°〜+51°` の角度範囲に5方向の火球（弾幕）を同時発射する機能。

* 特殊攻撃機能（担当：木村）：空中でZキー押下時に無敵になりつつローリング攻撃を繰り出す機能

* 緊急回避機能（担当：金）：Cキー押下時に魔法使いが向いている方向にテレポートを行う機能

* マップ全体攻撃機能（担当：アコア）：Xキー押下時にアイテムを消費してマップ全体攻撃を行う機能
* ダブルジャンプ機能（担当：アコア）：空中にいる間、上キー押下で一度だけジャンプできる機能

* ボスエネミー機能（担当：金子）：一定距離進むと強敵のボスエネミーが出現する機能

### メモ

* クラス内の変数は，すべて，「get_変数名」という名前のメソッドを介してアクセスするように設計してある
* すべてのクラスに関係する関数は，クラスの外で定義してある
